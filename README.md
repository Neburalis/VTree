# VTree — поисковые деревья

Лабораторная работа №3 по C++ (2-й курс, курс К. И. Владимирова): динамическое
множество уникальных целых ключей с запросами по порядку, реализованное и
исследованное четырьмя разными способами.

Подробная постановка — в [IDEA.md](IDEA.md). Здесь — краткая выжимка.

## Задача

Поддерживать множество уникальных `int`-ключей и четыре операции:

| Команда | Смысл | Сложность (цель) |
|---|---|---|
| `k x` | вставить ключ `x` (повторная вставка игнорируется) | `O(log n)` |
| `q l r` | число ключей в интервале `(l, r]` | `O(log n)` |
| `m i` | `i`-й наименьший ключ, `i` считается с единицы | `O(log n)` |
| `n x` | число ключей, строго меньших `x` | `O(log n)` |

Пример:

```text
Вход:      k 8 k 2 k -1 m 1 m 2 n 3 q -1 8
Результат: -1 2 2 2
```

## Сравниваемые реализации

1. `std::set`;
2. упорядоченный `std::vector`;
3. собственное AVL- или красно-чёрное дерево с размером поддерева в узле;
4. четвёртая структура или оптимизация по выбору.

| Структура | Вставка | `q l r` | `m i` | `n x` |
|---|---:|---:|---:|---:|
| `std::set` | `O(log n)` | `O(log n + k)` | `O(n)` | `O(n)` |
| Упорядоченный `std::vector` | `O(n)` | `O(log n)` | `O(1)` | `O(log n)` |
| Дополненное AVL/RB-дерево | `O(log n)` | `O(log n)` | `O(log n)` | `O(log n)` |

`k` — число элементов в найденном диапазоне. Асимптотики недостаточно: нужны
измерения, показывающие, где каждая структура реально выигрывает.
